# Khirale Home Assistant Add-ons

Dépôt officiel des add-ons Home Assistant développés par Khirale.

## Add-on disponible

### Khirale IzyPower MQTT Gateway

Passerelle MQTT locale entre Home Assistant, le VPS Khirale et les équipements
IzyPower. Elle décode les messages ENC1, publie une vue locale lisible et
contrôle les flux autorisés pour chaque numéro de série.

## Ajouter le dépôt dans Home Assistant

Dans Home Assistant :

1. ouvrir **Paramètres → Modules complémentaires → Boutique des modules complémentaires** ;
2. ouvrir le menu **Dépôts** ;
3. ajouter l'adresse suivante :

```text
https://github.com/khirale/HA_Addon_Izypower-MQTT
```

4. installer **Khirale IzyPower MQTT Gateway** depuis la boutique.

Home Assistant OS ou une installation Supervised est nécessaire pour utiliser
les add-ons.
